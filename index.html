Supabase & Cloud Sync Settings

To enable GitHub Sign-In and save your counters in the cloud, enter your free Supabase project credentials.

Found in Supabase Dashboard → Project Settings → API
Found in Supabase Dashboard → Project Settings → API (anon public)
GitHub OAuth Callback URL:

In your GitHub OAuth App settings, set the Authorization callback URL to:

https://YOUR_PROJECT_ID.supabase.co/auth/v1/callback

How to Publish on GitHub Pages with GitHub Login

1

Create a GitHub Repository

Create a repository on GitHub (e.g. contest-counter or <username>.github.io).

2

Push These Files

Push index.html, style.css, app.js, and config.js to your repo.

3

Enable GitHub Pages

Go to your GitHub repo → Settings → Pages → select Deploy from a branch (branch: main, folder: / (root)) → click Save.

Your URL will be: https://<username>.github.io/<repo-name>/

4

Create Free Supabase Database

Go to supabase.com, create a project, and run the SQL table script provided in README.md.

5

Enable GitHub OAuth

In GitHub Settings → Developer Settings → OAuth Apps, create an App. Paste the Client ID and Secret into Supabase → Authentication → Providers → GitHub.
