Generate Token on GitHub ↗

How to Publish to GitHub Pages

1

Push Files to GitHub

Create a repository (e.g. cp-counter or <username>.github.io) and push these files (index.html, style.css, app.js).

2

Enable GitHub Pages

In your repo → Settings → Pages → select Deploy from a branch (branch: main, folder: / (root)) → click Save.

Your URL will immediately be: https://<username>.github.io/<repo-name>/

3

Connect Your Account

Open your site, click Connect GitHub, and generate a token with gist permission. Your counters will auto-save to a private Gist under your GitHub profile!
